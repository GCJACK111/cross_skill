# 横向综合输出模板

回复正文与 PDF 正文使用同样的三个一级部分。内部证据底表、科学问题分析、矩阵及核查记录不另展示。

## 1 研究思路覆盖率分布图

插入由当前文献矩阵生成的横向条形图。标题含 N，每条显示百分比与篇数。

图注：图 1  当前文献研究思路覆盖率（N = 实际计入统计的独立论文数；允许多重归属）。在图注或紧接的一两句中交代外围材料、综述与编号缺口的处理，不另立材料章节。

## 2 Introduction 完整写法思路

**主线：** Importance → 从当前文献归纳的第一层判断 → 第二层判断 → 第三层判断。用一句话写清实质内容和推进关系，不将占位名称直接作为答案。

### 第1段：Importance

从材料支持的客观现象、实际需求或具体后果说明研究为何重要，段末引出贯穿后文的共同问题。

### 第2段：文献归纳的第一层中心判断

承接共同问题，综合第一层已有回答，说明它引出的进一步需求。

### 第3段：文献归纳的第二层中心判断

由第2段提出的需求引入新增考虑，说明怎样深化已有回答，以及下一步需要回答什么。

### 第4段：文献归纳的第三层中心判断

继续回应第3段的问题，比较第三层进展及最近邻工作，定位具体待解释或待验证的关系，在本段末尾收束到本文目标、实际方法及贡献；自身工作缺失时仅留一句具体占位。

以上四个写作单元各给出：**主题句、充分展开的论证与文献依据、过渡句／收束句**。引用沿用编号或作者年份，与具体判断对应。后三段的层次从材料归纳，不固定为空间—时间—时空等标签，也不把每个图表类别各写一段。每次递进解释“已有答案—进一步需求—新增考虑”；并列路线可在同一层内综合，不制造历史替代关系。

不另加第5段或独立的背景、缺口、本文工作段，不在四个单元内部再拆出额外的 Introduction 自然段。

## 3 主要分布与思路边界

按第一部分的类别逐项写出：篇数／N（百分比）、实际机制、已有答案与适用条件、与目的有关的边界及支撑文献。说明时间输入、时变输出、固定关系序列处理与动态关系更新等差异时，紧接具体方法事实，不追加防御性收尾。

不再追加摘要、关键句摘录、科学问题列表、研究建议、证据矩阵、附录或总结章节。最终只交付一个包含这三部分的完整 PDF，并同步本轮修改。图表嵌入其中，正文之外只放这一个 PDF 的下载链接；图片、独立图 PDF、DOCX、CSV、JSON、TEX 和 ZIP 等中间文件均留在内部。

If a sentence serves only to preempt criticism rather than advance the argument, delete it.
