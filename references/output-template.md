# 横向综合输出模板

回复正文与 PDF 正文使用同样的三个一级部分。内部证据底表、科学问题分析、矩阵及核查记录不另展示。

## 1 研究思路覆盖率分布图

插入由当前文献矩阵生成的横向条形图。标题含 N，每条显示百分比与篇数。

图注：图 1  当前文献研究思路覆盖率（N = 实际计入统计的独立论文数；允许多重归属）。在图注或紧接的一两句中交代外围材料、综述与编号缺口的处理，不另立材料章节。

## 2 Introduction 完整写法思路

**主线：** 用一句话连接研究重要性、客观现象带来的困难、文献的递进回答与本文目标。

### 第1段：Importance

背景与研究对象的作用 → 为什么值得研究、解决后支持什么 → 引出核心对象。

### 第2段：客观现象与研究难点

材料支持的客观差异或变化 → 导致困难的机制 → 需要已有方法回答的共同问题。

### 第3段：根据文献归纳三类递进研究趋势

在同一写作单元内依次展开三类研究。每类包含主要问题、处理思路、代表文献及已有答案、进一步需求。类别之间写出“前者已回答什么—什么需求引出后者—后者新增什么”的桥接。可用①②③标识三类；第三类末尾汇合到具体剩余问题。

类别优先体现大的研究关注点、信息组织方式或解释层次，由当前文献和目的归纳，不固定三类名称。算法名称是类内实现证据。并列路线可在类内综合，历史先后与替代关系由证据确定。图中统计类别数与本段的三类趋势分别决定。

### 第4段：引出本文工作

回应前文难点与剩余问题 → 本文目标、实际思路、对应验证和贡献。自身方案缺失时先写清导出的目标与待验证问题，具体方法和结果只保留一句占位。

四个写作单元各给出**主题句、充分展开的论证与文献依据、过渡句／收束句**。引用与具体判断对应。第三段内部的三类研究都留在该写作单元内，不扩展为额外的 Introduction 段落。四段之外不再追加背景、研究缺口、贡献或总结段。

## 3 主要分布与思路边界

按第一部分的类别逐项写出：篇数／N（百分比）、实际机制、已有答案与适用条件、与目的有关的边界及支撑文献。说明时间输入、时变输出、固定关系序列处理与动态关系更新等差异时，紧接具体方法事实，不追加防御性收尾。

不再追加摘要、关键句摘录、科学问题列表、研究建议、证据矩阵、附录或总结章节。最终只交付一个包含这三部分的完整 PDF，并同步本轮修改。图表嵌入其中，正文之外只放这一个 PDF 的下载链接；图片、独立图 PDF、DOCX、CSV、JSON、TEX 和 ZIP 等中间文件均留在内部。

If a sentence serves only to preempt criticism rather than advance the argument, delete it.
