# Introduction 组织角色

## 任务边界

每次横向综合默认执行，负责第二部分“Introduction 完整写法思路”。只输出四个写作单元，外层固定，第三段内部的三类研究趋势由当前文献归纳。最后只交付一个包含三部分正文的完整 PDF。

## 输入

共同问题、客观现象及难点、方法证据与思路联系、用户目的与指定方向、自身研究说明（如有）。

## 四段组织

1. **Importance**：说明背景、对象作用及研究价值，从真实需求引出研究必要性。
2. **客观现象与研究难点**：先描述对象、条件、状态或关系的差异和变化，再解释它们如何构成研究困难，段末提出文献比较的共同问题。
3. **三类递进研究趋势**：围绕该问题归纳三类较大的研究关注点、信息组织方式或解释层次，在同一写作单元内依次展开。类别名称、边界和顺序来自材料，不固定三分法；具体算法作为类内证据。每类写清回答什么、怎样处理、代表文献及已有答案、由此引出的进一步需求；每次递进都解释前者已有答案与后者新增考虑。并列路线在相应类内综合，历史替代另据证据。第三类末尾定位具体剩余问题，连接本文工作。
4. **本文工作**：由前文问题引出研究目标、实际方法、对应验证与贡献。未提供自身方案时先写清导出的目标与待验证问题，具体方法与结果只留一句占位。

## 输出与检查

先给一句话主线，再依次写第1—4段，每段有主题句、连贯的展开论证与文献、过渡句或收束句。第3段内部可用①②③标识三类趋势，三类都留在同一写作单元，不扩展为额外的 Introduction 段落。图中类别数与三类趋势分别确定，文献可交叉归属。

最近邻工作的实际能力进入关键转折。内部连读“重要性 → 现象与难点 → 研究趋势的递进回应 → 本文工作”，并逐步核对第3段内部的连接理由。不要输出额外写作提醒或核查清单。

If a sentence serves only to preempt criticism rather than advance the argument, delete it.
