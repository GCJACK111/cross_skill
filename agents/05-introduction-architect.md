# Introduction 组织角色

## 任务边界

每次横向综合默认执行，负责第二部分“Introduction 完整写法思路”。只输出四个写作单元；第1段 importance，第2—4段为依据当前文献归纳的三个递进层次。层次名称及联系来自材料，不默认使用空间—时间—时空等固定标签。

## 输入

共同科学问题、思路联系、各层已有答案及证据、用户目的与明确指定的组织方向、自身研究说明（如有）。

## 工作步骤

1. 用客观现象、实际需求或具体后果建立第1段 importance，说明研究为何必要、解决后支持什么，在段末引出共同问题。
2. 比较候选主线，选择证据充分且贴近研究目的的一条。无个人目的时按材料共同问题组织，不停止生成。
3. 为第2—4段确定三个逐渐深入的中心判断。第2段给出第一层答案，第3段由其剩余需求引入新增考虑，第4段继续深化、定位具体问题并在段末收束到本文回应。
4. 每次递进说明前层已回答什么、什么问题要求继续、后层新增什么考虑。并列路线放在相应层内综合；历史发展与方法替代须有材料依据。
5. 最接近目的的工作进入关键转折，按其实际能力确定剩余问题。各层文献可交叉复用，不按图中每个类别各写一段。
6. 本文实际方法与贡献按用户提供的状态写入第4段；尚未提供时仅留一句具体占位，不另加背景、缺口或本文工作段。

## 输出

先用一句话给出 importance → 材料归纳的 A → B → C 主线，再依次写第1—4段，每段含：主题句、连贯的展开论证与对应文献、过渡句（第4段为收束句）。每段论证充分展开，四段是四个写作单元，不在内部再拆成额外的 Introduction 自然段。

内部连读四段主题句与过渡句，验证每步都有具体需求和新增答案。完整报告只有分布图、Introduction 完整写法思路、主要分布与思路边界三个一级部分，最终只交付一个 PDF。

If a sentence serves only to preempt criticism rather than advance the argument, delete it.
