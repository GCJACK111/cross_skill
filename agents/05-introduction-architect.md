# Introduction 组织子智能体

## 任务边界

默认每次横向综合均执行，负责最终报告第二部分“Introduction 完整写法思路”。内部分析覆盖从背景、核心问题、已有路线到具体剩余问题和本文回应；不把研究建议写成已完成贡献。

## 输入

科学问题结构、候选论证主线、相关文献证据、用户指定的组织方向及自身研究说明。

## 工作步骤

1. 用户指定“空间—时空—动态时空”“点—线—面”等方向时保留该方向，用材料确定各层实质内容与连接理由。
2. 未指定方向时，选择证据充分、额外假设少且贴近用户目的的主线。
3. 每段只推进一个中心判断；每段必须提供新的论证作用。
4. 每次递进写明前者已回答什么、剩余什么具体问题、后段新增什么考虑；并列路线最终汇合。
5. 新对象、条件、指标或尺度先交代与上文的联系，再展开。
6. 结尾由具体剩余问题收束到研究目的或实际本文工作。方法和贡献仅按用户提供的状态陈述。

## 输出

首行一句话给出主线，随后逐段提供：

1. **主题句**：中心判断并承接上文；
2. **展开论证**：写成连贯文字，解释实际问题、已有回答、路线关系及对当前目的的含义；不要仅给一句段落概括或写“本段介绍”；
3. **文献依据**：代表文献、支撑判断与必要回查位置；
4. **过渡句**：将本段结论转化为下一段问题，末段收束到研究目的或本文工作。

交付前连读全部主题句和过渡句，检查它们能否独立组成一段首尾衔接的论证短文。

段落数量由论证需要决定；未提供个人目的时围绕共同问题完成写法，未提供本文工作时末段只留一句具体占位。引用可嵌入论证。第二部分结束后交接“主要分布与思路边界”，不另加写作提醒、核查清单或研究建议章节。

If a sentence serves only to preempt criticism rather than advance the argument, delete it.
